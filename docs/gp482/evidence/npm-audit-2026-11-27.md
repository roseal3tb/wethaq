# Dependency vulnerability review — 2026-11-27

`npm audit` was run in the three npm projects (dashboard, `wethaq-api`, `chaincode/shipment`) against the public
npm advisory database on 2026-11-27.

## Before

| Project | Critical | High | Moderate | Packages |
| --- | --- | --- | --- | --- |
| Dashboard (root) | 2 | 1 | 5 | vitest 2.1.9 and its tooling (tinypool, vite-node, vite 5 inside vitest, esbuild, @vitest/mocker); react-router / react-router-dom 6.30.6 |
| wethaq-api | 2 | 1 | 3 | vitest 2.1.9 and its tooling |
| chaincode/shipment | 2 | 1 | 3 | vitest 2.1.9 and its tooling |

The 6 findings reported by `npm install` in `wethaq-api` (3 moderate, 1 high, 2 critical) are this vitest chain.

Assessment:

- **vitest chain (critical/high/moderate)** — test-runner only. It is not part of the dashboard bundle, the API
  container (`npm ci --omit=dev`) or the chaincode container. The advisories concern the Vitest UI/dev server and
  worker options, which this project does not expose. Still fixed, because the upgrade has no runtime effect.
- **react-router-dom 6 (moderate)** — shipped in the dashboard bundle. The advisories are open redirects through
  crafted `<Link>`/`navigate()` targets; the dashboard only navigates to its own fixed routes, so exposure was
  low, but this is a runtime dependency and was fixed.

## Changes

| Project | Change |
| --- | --- |
| Dashboard | `vitest` ^2.1.8 → ^4.1.12; `react-router-dom` ^6.30.1 → ^7.18.7 (runtime: react-router 7.18.7, cookie, set-cookie-parser added; @remix-run/router removed) |
| wethaq-api | `vitest` ^2.1.8 → ^4.1.12 (no runtime dependency changed) |
| chaincode/shipment | `vitest` ^2.1.8 → ^4.1.12 (no runtime dependency changed) |

vitest 4.1.12 was chosen over 5.x because 5.x requires Node 22.12 or newer; 4.1.12 supports Node 20 and 22.

## After

`npm audit` reports **0 vulnerabilities** in all three projects (runtime and development dependencies).

Checks re-run after the upgrade, all passing: dashboard typecheck, 20 unit tests, production build, 54 Playwright
demo tests (2 skipped by design), 6 Playwright live tests; API typecheck and 71 tests (7 Fabric tests skipped
without the network); chaincode 24 tests; Fabric Playwright end-to-end test.

## Continuous check

`.github/workflows/checks.yml` has an `audit` job for the three projects: it fails on any moderate or higher
advisory in runtime dependencies, and on any high or critical advisory in development dependencies. New
advisories are published continuously, so a future run can fail without any change in this repository.
